# 八、Lua 脚本

## 8.1 基础

- `type()`：获取变量的类型，返回值类型是 string；判断为空时与 `"nil"` 比较（`type(x) == "nil"`）。
- `require`：加载文件并执行其中的代码；`./` 表示当前文件夹下的文件，`../` 表示上一级文件夹。

### 8.1.1 table 的底层结构

- table 是**混合结构**，由两部分组成：
  - **数组部分（Array Part）**：存储连续的数字索引键，类似传统数组；
  - **哈希部分（Hash Part）**：存储非数字键，通过哈希表实现。
- 内存分配是**动态的**；常见数据结构是 string 和 table。

## 8.2 遍历：ipairs 与 pairs

| 对比项 | ipairs | pairs |
| --- | --- | --- |
| 遍历范围 | 只遍历**数组部分**（整数键） | 遍历表中**所有键值对**（数组 + 哈希） |
| 起始/终止 | 从索引 1 开始依次递增，**遇到 nil 立即停止** | 遍历所有有效键，顺序不固定（依赖哈希实现） |
| 非数字键 | 忽略 | 包含 |
| 适用 | 数组型表 | 混合键表 |

## 8.3 元表与元方法

### 8.3.1 什么是元表/元方法

- 元表（metatable）是一个普通 Lua 表，可关联到另一个表上，通过特定键（元方法）定义表对某些操作的响应。
- 当对表执行某操作而表本身没有直接定义时，Lua 会查找其元表中的对应元方法。
- 常用元方法：算术（`__add`/`__sub`/`__mul`/`__div`/`__mod`/`__unm`/`__pow`）、比较（`__eq`/`__lt`/`__le`）、连接（`__concat`）、长度（`__len`）、索引（`__index`/`__newindex`）、调用（`__call`）。

### 8.3.2 __index、__newindex、__call、__tostring、rawset、rawget

| 元方法 | 触发时机 |
| --- | --- |
| `__index` | **查询**：获取当前表**没有的键**时，去元表的 `__index` 查找（`__index` 可以是表或函数） |
| `__newindex` | **赋值**：给当前表**没有的键**赋值时调用；若 `__newindex` 是一个表，则对该表字段赋值 |
| `__call` | 把表**当作函数调用**时调用 |
| `__tostring` | 表被当作字符串使用/输出时调用（如 `print(t)`） |
| `rawset` | **绕过元方法**直接设置表字段 |
| `rawget` | **绕过元方法**直接获取表字段 |

- 区别一句话：`__index` 用于**查询**，`__newindex` 用于**更新**。

## 8.4 面向对象

### 8.4.1 Lua 如何实现 OOP 三大特性

- **封装**：利用 table 封装数据与方法。
- **继承**：利用**元表 + __index** 模拟：
  - 设置子类的元表为父类；父类的 `__index` 指向父类自己；
  - 子类身上找不到属性/方法时，会查找元表的 `__index`（即父类中的内容），从而模拟继承。
- **多态**：子类自己实现同名方法即可（覆盖父类版本）。

### 8.4.2 Lua 实现 C# 的 new 构造

- 思路：把 `new` 传入的参数表作为本地表 o；把"类"（self）作为元表，设置元方法 `__index` 指向类自身；返回 o。调用 `new` 时实际访问的是元表（类）中的内容，从而模拟 C# 的 new + 构造函数。

## 8.5 进阶

### 8.5.1 闭包

- 当一个函数嵌套另一个函数时，内部函数可以访问外部函数的局部变量，**即使出了外部函数的作用域依然成立**（变量被捕获，生命周期延长）。

### 8.5.2 深拷贝与浅拷贝

- **浅拷贝**：只复制对象的**引用**，不复制对象本身；修改原对象会影响拷贝后的对象（共享同一份数据）。
- **深拷贝**：创建原始对象的**完整拷贝**（含所有嵌套表），完全独立，互不影响。
- 实现深拷贝：**递归遍历**表并复制其所有内容（注意处理嵌套表、防止循环引用）。

### 8.5.3 userdata

- userdata：**用户自定义数据类型**。
- 当 C、C++、C# 与 Lua 产生交互时传入/传出的数据统称为 userdata，主要用来存储与外界交互产生的数据类型。

### 8.5.4 实现 table 的迭代器

- 直接使用 `pairs` 或 `ipairs` 实现；也可以自定义迭代器函数（闭包 + 状态变量）实现特定遍历逻辑。

## 8.6 Lua 与 C / C# 交互

### 8.6.1 Lua 与 C 交互原理

- 通过**栈**交互（类似 C 函数调用栈）：
  - C 调用 Lua：Lua 把值**压入栈**，C 再从栈中取值；
  - Lua 调用 C：C 将数据压入栈，Lua 从栈中取值。
- 正数索引表示从**栈底**开始到栈顶；负数索引表示从**栈顶**开始到栈底。

### 8.6.2 C# 与 Lua 交互原理

- 同样通过**虚拟栈**实现：
  - **C# Call Lua**：C# 把数据放入栈 → Lua 从栈取数据 → 结果返回栈顶 → C# 从栈顶取出；通过**桥文件访问 dll** 实现访问。
  - **Lua Call C#**：C# 源文件生成 **Wrap 文件**或生成 C 模块，注册到 Lua 解析器，Lua 调用该模块的函数（如 xLua/ToLua 框架原理）。

## 8.7 内存、GC 与热更新

### 8.7.1 Lua 的 GC 原理（三色标记）

- 标记阶段：遍历所有**可达**对象，标记为活跃。
- 清理阶段：遍历待析构/未标记对象，把其中仍被引用的对象标记为活跃。
- 清除阶段：回收所有未被标记为活跃的对象。
- 析构阶段：调用清理阶段分离出的对象的析构器。
- 每个对象有三种状态：
  - **白色**：无法被访问（初始状态），清除阶段回收；
  - **灰色**：可访问但未标记（已访问、子对象未访问）；
  - **黑色**：已标记（已访问且子对象已完全访问）。

### 8.7.2 Lua 如何实现热更新

1. 从服务器下载**资源比对文件**；
2. 把下载的文件与**本地资源比对文件**比较；
3. 删除本地旧的比对文件，**下载新的 AB 包**（含 Lua 逻辑）。

### 8.7.3 AB 包资源加载的方法（Lua 侧涉及）

1. 从本地文件加载（LoadFromFile）；
2. 从本地内存加载（LoadFromMemory）；
3. WWW 网络加载；
4. UnityWebRequest 网络加载；
5. 通过 Manifest 文件加载（含依赖管理）。
