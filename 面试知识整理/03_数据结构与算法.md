# 三、数据结构与算法

## 3.1 线性结构

### 3.1.1 链表与数组的区别

| 对比项 | 数组 | 链表 |
| --- | --- | --- |
| 存储 | 连续内存 | 节点分散，通过指针连接 |
| 访问 | 随机访问 O(1) | 需遍历 O(n) |
| 插入/删除 | 移动元素 O(n) | 已知节点时 O(1) |
| 空间 | 可能浪费（预分配） | 每个节点额外存指针 |
| 适用 | 读多写少、按下标访问 | 频繁插入删除、长度不确定 |

### 3.1.2 单链表反转

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode *prev = nullptr, *cur = head;
    while (cur) {
        ListNode* next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
```

### 3.1.3 队列与栈的异同

- 栈：LIFO（后进先出），只在一端操作，适合 DFS、撤销、括号匹配。
- 队列：FIFO（先进先出），一端入一端出，适合 BFS、任务调度。

### 3.1.4 用两个栈实现一个队列

- 入队：压入 `stackIn`。
- 出队：若 `stackOut` 为空，把 `stackIn` 全部弹出并压入 `stackOut`，再从 `stackOut` 弹出（栈颠倒两次即得 FIFO）。

## 3.2 排序算法

### 3.2.1 时间复杂度总表

| 排序 | 平均 | 最坏 | 最好 | 空间 | 稳定性 |
| --- | --- | --- | --- | --- | --- |
| 冒泡 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 插入 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 快速 | O(n log n) | O(n²) | O(n log n) | O(log n) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 基数 | O(d·(n+k)) | O(d·(n+k)) | O(d·(n+k)) | O(n+k) | 稳定 |

### 3.2.2 快速排序（C++ 实现，来自笔记）

```cpp
#include <iostream>
using namespace std;

// 分区函数
int partition(int arr[], int low, int high) {
    int l = low, r = high, pivot = arr[low];
    while (l < r) {
        while (l < r && arr[r] > pivot) r--;
        if (l < r) swap(arr[l++], arr[r]);
        while (l < r && arr[l] < pivot) l++;
        if (l < r) swap(arr[l], arr[r--]);
    }
    return l; // 返回基准值的位置
}

// 快速排序函数
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}
```

### 3.2.3 其他排序要点

- **冒泡**：相邻两两比较交换，每轮把最大（小）值冒到末尾。
- **直接插入**：把新元素插入到已排好序的前缀中（类似整理扑克牌）。
- **直接选择**：每轮选剩余最小（大）值与当前位置交换。
- **归并**：分治，两两合并有序段，稳定但需 O(n) 额外空间。
- **堆排序**：利用大/小顶堆，堆顶与末尾交换后调整，O(n log n)。
- **基数排序**：按位（个位、十位…）分配收集，适合整数/定长字符串。

## 3.3 查找

### 3.3.1 二分查找

```cpp
int binarySearch(int arr[], int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;   // 防溢出
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1; // 未找到
}
```

### 3.3.2 二叉排序树 / 平衡树 / 红黑树 / B 树

| 结构 | 规则要点 | 查找复杂度 |
| --- | --- | --- |
| 二叉排序树（BST） | 左节点 < 根 < 右节点 | 平均 O(log n)，退化为链表时 O(n) |
| 平衡二叉树（AVL） | 满足 BST；任意节点左右子树高度差不超过 1；插入删除后可能破坏平衡，需找最小不平衡子树调整，开销大 | O(log n) |
| 红黑树（RBT） | 满足 BST；插入删除很少破坏规则，调整是常数级时间 | O(log n) |
| B 树（m 阶多路平衡查找树） | 除根节点外，任何节点至少有 ⌈m/2⌉ 个分叉；任一节点所有子树高度相同 | O(log n)，适合磁盘/数据库 |
| B+ 树（m 阶） | 非根叶子节点至少 ⌈m/2⌉ 棵子树；所有数据在叶子节点，叶子间有序链表 | O(log n)，数据库索引常用 |

**各自定义：**

- **二叉排序树（BST）**：二叉树，满足左子树所有节点 < 根节点 < 右子树所有节点，左右子树各自也是 BST；中序遍历得到递增有序序列。
- **平衡二叉树（AVL）**：在 BST 基础上，任意节点的左右子树高度差（平衡因子）绝对值不超过 1；插入/删除后失衡时通过旋转（LL/RR/LR/RL）恢复平衡，是严格平衡的二叉查找树。
- **红黑树（RBT）**：在 BST 基础上节点带红/黑颜色，满足 5 条性质：节点非红即黑；根为黑；叶子（NIL）为黑；红节点的两个子节点都是黑（红节点不能连续）；任一节点到其每个叶子的路径包含相同数目的黑节点。最远路径不超过最近路径的 2 倍，属近似平衡，插入/删除后通过变色 + 旋转调整。C# 的 `SortedDictionary`/`SortedSet` 底层就是红黑树。
- **B 树（m 阶多路平衡查找树）**：多路平衡查找树，每个节点可存多个关键字和多棵子树，所有叶子在同一层（树高一致）；除根节点外每个节点至少有 ⌈m/2⌉ 棵子树。多路结构降低树高、减少磁盘 IO，适合磁盘/数据库存储。
- **B+ 树**：B 树的变体，所有数据都存放在叶子节点，内部节点只存索引关键字，因此能容纳更多索引项、树更矮；叶子节点间用指针构成有序链表，便于范围查询和顺序遍历，数据库索引（如 MySQL InnoDB）常用。

## 3.4 哈希表

### 3.4.1 哈希表原理、冲突解决与适用环境

- **原理**：通过哈希函数把键映射为数组下标，O(1) 定位。
- **冲突解决**：链地址法（桶内链表）、开放定址法（线性探测/二次探测/再哈希）。
- **扩容**：元素超过负载因子后扩容并重新哈希。
- **适用**：查重、按键快速取值（Dictionary/HashSet/缓存）；不适合有序遍历、范围查询。
- C# `Dictionary` 底层（桶 + 条目、链地址、扩容到质数）详见 §1.3.2。

## 3.5 树与图

### 3.5.1 树与图的遍历：BFS 与 DFS

| 对比项 | BFS（广度优先） | DFS（深度优先） |
| --- | --- | --- |
| 遍历方式 | 逐层遍历，先访问根再访问所有相邻节点 | 沿一条路径深入到底，再回溯探索其他路径 |
| 数据结构 | 队列（FIFO） | 栈（LIFO）；递归实现用系统调用栈 |
| 空间复杂度 | 最坏 O(n)（如完全二叉树），n 为节点数 | 取决于深度，最坏 O(h)，h 为最大深度 |
| 适用场景 | 最短路径、层次遍历 | 拓扑排序、连通性检测、路径搜索 |

### 3.5.2 拓扑排序与逆拓扑排序

- **拓扑排序**：找到**入度为 0** 的点开始构建（做事有先后顺序的场景，如依赖任务）。
- **逆拓扑排序**：找到**出度为 0** 的点开始构建。

### 3.5.3 最小生成树

- **定义**：带权无向**连通图**中，选出 n-1 条边把所有顶点连通、且**总权值和最小**的生成树。对该问题，局部贪心即可得到全局最优（贪心选择性质）。

| 对比项 | Prim 算法 | Kruskal 算法 |
| --- | --- | --- |
| 策略 | 找**顶点** | 找**边** |
| 核心思想 | 从任一顶点出发，维护已选集合 U 与未选集合，每次选连接两集合的**最小权边**，把该顶点并入 U，直到全部顶点并入 | 所有边**按权值从小到大**排序，依次取边，用**并查集**判断两端点是否已连通（成环则跳过），直到选够 n-1 条边 |
| 关键数据结构 | 已选集合 + 优先队列（取最小边） | 边排序 + 并查集（判环） |
| 时间复杂度 | 邻接矩阵 O(V²)；优先队列优化 O(E log V) | O(E log E)（主要开销在排序） |
| 适合场景 | 稠密图 | 稀疏图 |

- 都只适用于带权**无向连通图**；生成树边数恒为 n-1（n 为顶点数）。
- 典型应用：修路、网络布线——使所有节点连通且总成本最小。

### 3.5.4 最短路径

- **松弛（Relaxation）**：三者共同基础——若 `dist[v] > dist[u] + w(u,v)`，则更新 `dist[v]`（经 u 到 v 更短）。

| 对比项 | Dijkstra | Bellman-Ford | Floyd |
| --- | --- | --- | --- |
| 类型 | 单源（一个起点到所有点） | 单源 | 多源（任意两点之间） |
| 核心思想 | 贪心：每次从未确定的点中取 dist 最小的点（优先队列），松弛其出边，点一旦确定不再改变 | 对全部边做 **n-1 轮**松弛（最短路径最多含 n-1 条边）；**第 n 轮仍能松弛 → 存在负环** | 动态规划：`dp[i][j] = min(dp[i][j], dp[i][k]+dp[k][j])`，k 为中间点（可滚动为二维） |
| 边权要求 | **不能有负权边**（负权使贪心失效） | 可处理负权边 | 可处理负权边，但不能有负环 |
| 负环检测 | 不能 | 能 | 能（对角线 `dp[i][i] < 0` 即存在） |
| 时间复杂度 | O((V+E) log V)（堆优化） | O(V·E) | O(n³)，空间 O(n²) |
| 适用场景 | 非负权图单源最短路（最常用） | 有负权边、需检测负环 | 顶点少、求所有点对最短路 |

## 3.6 寻路算法：A*（A Star）

### 3.6.1 原理

**核心思想**：A* = Dijkstra + 启发式。每次从"综合代价最小"的节点扩展——既统计已走过的实际代价 G，又预估到终点的剩余代价 H，让搜索**朝终点方向推进**，而不是像 Dijkstra 那样向四周均匀扩散。

**三个值的计算**：

- **G（起点 → 当前节点的实际代价）**：沿已找到的路径累计。邻居的 `G = 当前节点 G + 移动代价`（正交一般为 1、斜向为 √2，按地图权重定）；起点 G = 0。
- **H（当前节点 → 终点的预估代价）**：直接用启发函数从坐标算出，与路径无关（公式见 3.6.2），如曼哈顿距离。
- **F（总代价）**：`F = G + H`，开放列表每次取 F 最小的节点扩展（F 相同取 H 小的，路径更优）。

**两个列表**：

- **OpenList（开放列表）**：已发现、待扩展的节点，按 F 排序（优先队列/小顶堆），每次弹出 F 最小的节点。
- **ClosedList（关闭列表）**：已扩展过的节点，不再处理，避免重复扩展与死循环。

**完整流程**：

1. 起点入 OpenList：G = 0，计算 H、F，父节点记为 null。
2. 循环直到 OpenList 为空：
   - 弹出 F 最小的节点 n；若 n 是终点 → 成功，跳到步骤 4；
   - n 移入 ClosedList；
   - 遍历 n 的每个可行邻居 m（跳过障碍物与已在 ClosedList 的节点）：
     - 计算 `新 G = G(n) + 移动到 m 的代价`；
     - m 不在 OpenList → 加入，记录 G/H/F 与父节点 n；
     - m 已在 OpenList 且新 G 更小 → 更新 m 的 G、F 与父节点（换更优的父）。
3. OpenList 为空仍未找到终点 → 无可行路径，结束。
4. **路径重建**：从终点沿父节点指针一路回溯到起点，逆序即最短路径——所以每个节点必须记录父节点。

**关键结论**：

- H ≡ 0 时 A* 退化为 **Dijkstra**（只按 G 扩展，均匀扩散）。
- H 不超过真实代价（乐观估计）时，A* 保证找到**最优路径**；H 越接近真实代价，扩展节点越少、搜索越快。
- 移动代价为正时满足一致性，每个节点只需扩展一次（复杂度同 Dijkstra，但实际扩展数远少）。

### 3.6.2 启发式函数（H 的计算）

| 距离 | 公式 | 适用 |
| --- | --- | --- |
| 曼哈顿距离 | h(n) = \|x1-x2\| + \|y1-y2\| | 4 方向移动的网格地图 |
| 切比雪夫距离 | h(n) = max(\|x1-x2\|, \|y1-y2\|) | 8 方向移动的网格地图 |
| 欧几里得距离 | h(n) = √((x1-x2)² + (y1-y2)²) | 自由移动 |

- 8 方向更精确的对角距离：`min(dx, dy) × √2 + |dx - dy|`。
- 所有节点必须用**同一公式**计算 H；H 只是预估，不依赖障碍布局。

### 3.6.3 A* 优化

1. **二叉堆/优先队列**维护 OpenList：取最小 F 节点 O(1)、插入 O(log n)。
2. **跳跃点搜索（JPS）**：跳过对称路径，减少扩展节点（网格地图）。
3. **分层 A***：地图分区域，先规划粗略路径再细化局部路径。
4. **动态加权 A***：动态调整启发函数权重，平衡搜索速度与最优性。
5. **优化启发函数 H**：更接近真实代价可减少扩展。
6. **扩展 F = G + H + C**：C 为额外代价（如拐弯惩罚），减少不必要的转向。

## 3.7 其他考点

### 3.7.1 大端与小端

- **小端模式**：数据**低位**放在**低地址**，高位放在高地址（低位对应低地址）。
- **大端模式**：数据**高位**放在**低地址**，低位放在高地址。
- 读数据永远从低地址开始：小端模式从低位开始读，大端模式从高位开始读。

### 3.7.2 进制转换

- 十进制 → 二进制：**除 2 取余，倒序排列**。
- 二进制 → 八进制：**三位一组**（不够前补零），按 421 法将 1 对应的值相加。
- 二进制 → 十六进制：**四位一组**（不够前补零），按 8421 法将 1 对应的值相加。

### 3.8.6 二叉树遍历（先序/中序/后序/层序）

- **先序（前序）**：根 → 左 → 右；**中序**：左 → 根 → 右；**后序**：左 → 右 → 根（中序遍历 BST 得到有序序列）。
- 递归实现（以先序为例）：

```cpp
void preorder(TreeNode* root) {
    if (!root) return;
    visit(root);            // 根
    preorder(root->left);   // 左
    preorder(root->right);  // 右
}
```

- **层序（BFS）**：用队列，先根入队，出队时访问并依次将左右孩子入队。
- 迭代实现：先/中/后序用**栈**模拟递归（先序：栈压右再压左，出栈即访问）。
- 由遍历序列重建二叉树：先序/后序 + 中序可唯一确定二叉树（前序确定根，中序划分左右子树）。

### 3.8.7 KMP 字符串匹配

- **问题**：在文本串 S 中查找模式串 P 第一次出现的位置。
- **朴素算法**：逐个位置比对，失败后模式串只后移 1 位，最坏 O(n·m)。
- **KMP 核心**：匹配失败时**不回溯文本指针 i**，而是利用已匹配部分的信息把模式串**右移到合适位置**继续匹配，最坏 O(n+m)。
- **next 数组（部分匹配表/前缀函数）**：`next[j]` 表示 P[0..j-1] 中相等的最长真前后缀长度——即模式串第 j 位失配时，模式串应跳回的位置。

```cpp
// 计算 next 数组（前缀函数）
vector<int> getNext(const string& p) {
    int m = p.size();
    vector<int> next(m, 0);
    int k = 0;
    for (int j = 1; j < m; j++) {
        while (k > 0 && p[j] != p[k]) k = next[k - 1];
        if (p[j] == p[k]) k++;
        next[j] = k;
    }
    return next;
}

// KMP 匹配：返回 P 在 S 中首次出现的下标，不存在返回 -1
int kmp(const string& s, const string& p) {
    int n = s.size(), m = p.size();
    if (m == 0) return 0;
    vector<int> next = getNext(p);
    int j = 0;                       // 模式串指针，不回溯
    for (int i = 0; i < n; i++) {
        while (j > 0 && s[i] != p[j]) j = next[j - 1];
        if (s[i] == p[j]) j++;
        if (j == m) return i - m + 1;
    }
    return -1;
}
```
