- bool/int/float/指针与零值比较：`if (!b)`；`if (x == 0)`；`if (fabs(f) < 1e-6)`；`if (p == nullptr)`。

- 访问基类私有虚函数：友元类/友元函数。
- 实时系统基本特性：确定性、及时响应、可预测的调度。
- C++ 是否类型安全：C++ 不是完全类型安全的（C 风格转换、void*、联合等可绕过类型检查）。
- C++ 值传递方式：值传递、引用传递、指针传递。
- 开启新进程/线程：进程 `CreateProcess`（Windows）；线程 `CreateThread`（Windows）/ `std::thread`（C++11）。
- SendMessage 与 PostMessage：SendMessage 同步等待处理完成；PostMessage 异步投递消息后立即返回。
- 系统自动打开关闭的 3 个标准文件：stdin、stdout、stderr。
- 指针典型应用：动态内存、数组/字符串操作、函数参数（输出参数）、函数指针回调、链表等数据结构。
- Windows 消息系统构成 / 消息映射：消息队列 + 消息循环 + 窗口过程；MFC 用消息映射表把消息与处理函数关联。
