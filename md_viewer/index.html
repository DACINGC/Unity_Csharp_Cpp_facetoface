快捷键与操作
Ctrl+K聚焦搜索框（支持全文搜索正文）
Ctrl+F / F3在当前文档内查找（Enter 下一个 / Shift+Enter 上一个 / Esc 关闭）
↑ ↓在搜索结果中移动
Enter打开选中的搜索结果
Esc关闭弹层 / 收起搜索结果
顶部「首页 / 笔记 / 复习 / 统计」在独立工作台页面间切换；首页提供继续阅读、待复习与笔记入口，笔记页保留完整目录和知识点导航
点击 §编号跨文件跳转到对应知识点
点击标题行尾圆点设置：✓已掌握 / ◔待复习 / ✕薄弱；侧栏「待复习」会汇总需要回看的知识点
面包屑进度显示当前文档知识点掌握进度（掌握率 + 覆盖率 + ✓/◔/✕ 计数），随标记实时更新
点击「下个未标记」按标题顺序跳转到当前文档第一个未标记的小标题（知识点；跳过仅用于折叠分组的大标题）
点击左侧标题定位到当前文档对应小节
Ctrl+E编辑当前文档（Ctrl+S 保存、Esc 取消）

点击 ◐切换明暗主题
