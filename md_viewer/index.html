快捷键与操作

导航

↑ ↓在搜索结果中移动，Enter 打开
Alt+← / Alt+→打开上一篇 / 下一篇（按当前筛选范围）
[ / ]跳到当前文档的上一节 / 下一节
Esc依次关闭：掌握度菜单 → 更多操作 → 服务面板 → 搜索结果 → 查找栏 → 本弹层
顶部「首页 / 笔记 / 复习」在独立工作台页面间切换；复习页汇总薄弱与待复习项
点击 §编号跨文件跳转到对应知识点
浏览器 前进/后退在打开过的文档与小节之间导航

查找与阅读

Ctrl+K / /聚焦搜索框（跨文件全文搜索）
Ctrl+F / F3文档内查找（Enter 下一个 / Shift+Enter 上一个 / Esc 关闭）
滚动正文左侧目录自动高亮当前小节，顶部显示阅读进度条
面包屑进度本篇文章的掌握率 + 覆盖率 + ✓/◔/✕ 计数，随标记实时更新
点击侧栏按钮收起 / 展开侧栏（窄屏为抽屉）

掌握度

点击标题行尾圆点设置：✓已掌握 / ◔待复习 / ✕薄弱（右键圆点直接清除）
1 2 3 0对当前小节标记：已掌握 / 待复习 / 薄弱 / 清除
M打开当前小节的掌握度菜单
▸ 下个未标记按标题顺序跳到当前文档第一个未标记的小标题（跳过仅作折叠分组的大标题）
「复习」页汇总全部薄弱与待复习项，可点击直达原文

工具

R 或 🎲随机抽题自测（全部 / 待复习 / 薄弱）
Ctrl+E编辑当前文档（Ctrl+S 保存、Esc 取消）
T 或 ◐切换明暗主题（未手动切换时跟随系统）
🖨 打印打印当前文档 / 另存为 PDF
⏻ 服务控制顶栏电源按钮：查看服务状态、重启 / 关闭本地服务
?打开 / 关闭本帮助
