# 查看器界面与交互演进（md_viewer）

> 这份笔记是 `md_viewer`（面试 · 知识库本地查看器）**界面与交互的工程记忆**：每个决定是什么、为什么这么定、改动时必须守住什么。

## 硬约束（任何时候都不能破）

- **零依赖**：前端是单个 `md_viewer/index.html`（内联 CSS + JS），Markdown 渲染器 `md_viewer/renderer.js` 是纯函数、无 DOM 依赖；服务端 `mdviewer.py` 只用 Python 标准库。不引 npm、不引 CDN、不引字体。
- **只监听本机**：服务固定 `127.0.0.1:8765`，因此窄屏/抽屉布局只是"窄窗口适配"，不是手机可访问。
- **改完刷新即可**：`index.html` 与 `renderer.js` 由服务**每次请求从磁盘读取**，前端改动不需要重启服务；只有 `mdviewer.py` 改动才需要重启。
- **数据格式冻结**：复习进度导出仍为 `version 1` + `marks` / `events`，新增的本地状态（如最近打开 `mdviewer:recent`）**不进导出**——它属于设备本地导航状态，不是学习进度。
- **中文优先**：界面文案、代码注释、测试输出全部中文。

## 现在长什么样（已落地能力）

- **三个同级工作台**：首页（学习总览）/ 笔记（目录阅读）/ 复习（唯一的完整待复习清单，导航项带数量徽标）。学习进度、文件列表、知识点目录三块侧栏只在「笔记」阅读态出现。
- **首页**：继续阅读 → 3 张 KPI（知识点 / 待处理 / 复习次数）→ 三环（掌握率 / 覆盖率 / 薄弱占比）+ 状态明细与分段条 → 待复习 6 条 + 最近打开（无记录回落「笔记入口」）→ 知识点类型分布 → 近 12 个月复习热力图。
- **笔记**：左「我的笔记」按目录分组、可折叠、带类型筛选；右「知识点」树显示当前文档标题层级与数量；正文顶部阅读进度条、面包屑显示本篇掌握进度、目录滚动跟随。
- **复习**：薄弱优先的清单，点击回到原文；标记随之从清单移除。
- **掌握度**：目录行尾圆点（22px 命中区 + 7px 视觉点，颜色即状态），右键直接清除；侧栏「总进度」与面包屑「本篇」口径明确区分。
- **工具**：工具轨 🎲 抽题（全部 / 待复习 / 薄弱）、🖨 打印/导出 PDF、◐ 主题、? 帮助、⏻ 服务控制（状态/重启/关闭）、📁 在文件管理器中定位、✎ 内置编辑（`Ctrl+S` 保存、写前 `.bak` 备份）。
- **状态**：磁盘变更感知（面包屑「已更新」提示 + 一键重载并保持滚动位置）、阅读位置记忆、进度导入/导出、明暗主题防闪烁、`prefers-reduced-motion` 降级。
- **动效**：切换工作台/打开文档时内容区交叉过渡；卡片与列表错峰入场；当前小节用滑动指示条、页签用滑动指示片；进度环从 0 长出、色段从左侧展开、KPI 数字滚动到位；指针跟随柔光、条目悬停滑出强调条、标记脉冲。全部零依赖，且可被系统「减少动态效果」一键关闭。

## 一个功能一个入口（冗余收敛的决定）

这是这个项目最重要的界面原则：**同一件事只允许一个主入口**，多余的按钮删掉而不是保留成"快捷方式"。

| 能力 | 曾经的入口 | 现在的唯一入口 |
| --- | --- | --- |
| 待复习清单 | 侧栏「待复习」标签 + 复习工作台 + 首页 6 条预览 | 复习工作台（全量）+ 首页 6 条预览；侧栏标签整链路已删 |
| 待处理数量 | 侧栏标签徽标 + 首页卡片 + 复习页卡片 | 「复习」导航项徽标（0 时隐藏）+ 首页 KPI |
| 随机抽题 | 工具轨菜单 + 首页按钮 + 复习页按钮 + 移动菜单 | 工具轨 🎲 菜单（窄屏由「更多操作」镜像） |
| 首页数字 | 4 张卡（含与环重复的掌握率）+ 三环 + 状态拆分 | 比率用环、绝对值用 KPI，同一数字全页只出现一次 |

推论（写新功能前先问）：能由既有入口一跳到达的，不再加第二个入口；窄屏镜像菜单算响应式必需，不算重复。

## 设计系统

所有颜色 / 圆角 / 间距 / 动效都取 `:root` 令牌，组件里不写死色值：

- 深色默认（冷调中性）：`--bg #0e1013`、`--panel #14171b`、`--panel-raised #1a1e23`、`--border #262c34`、`--hairline`（发丝高光）、`--bg-glass` + `--blur`（玻璃粘性栏）、`--accent #3fbdfb` + `--accent-grad`、`--shadow-1/2/3`（`--shadow` 是 3 的别名）、`--r-sm/md/lg/pill`、`--ease` + `--dur-1/2/3`、`--focus-ring`、`--success/warning/error-soft`、`--doc-measure: 900px`。
- 浅色主题逐项对照。**曾经的浅色残色已修**：滚动条、`::selection`、表格斑马纹（`--row-stripe`）、代码块描边（`--code-border`）、面包屑底色、文件类型图标（`--icon-*`）、热力图色阶（`--heat-1..4`）。
- `<head>` 里有一段极小脚本，首帧之前设好 `data-theme`，因此切主题不闪屏。
- 交互可访问性：统一 `:focus-visible` 焦点环、`:active` 按压反馈、`prefers-reduced-motion: reduce` 关闭动画，`scrollBehavior()` 让"平滑滚动"在减少动效时退化为瞬时定位。

## 动效语言与降级

动效不是装饰，是"状态变化的可读性"：每个变化都要能看出**从哪来、到哪去**。约定如下：

- **令牌驱动**：曲线 `--ease-expo`（主力，快速起步柔和收尾）/ `--ease-spring`（小元素出现与按压）/ `--ease-in-out`；时长 `--dur-fast/base/slow/enter`；错峰步长 `--stagger`。组件里不写死时长与曲线。
- **位移克制**：入场位移 ≤ 8px、时长 0.14~0.52s；循环动效只允许环境光（数秒到数十秒）与进度流光（3.6s），绝不出现"永远在跳"的小元素。
- **编排**：容器加 `.stagger` 让前 10 个子项错峰升起；几百行的长列表（文件列表、目录）整块 `.reveal` 淡入，不逐行错峰。
- **指示物**：状态"在哪儿"用一条滑动的指示条表达（当前小节 `#toc-indicator`、页签 `#nav-indicator`），而不是给每个可选项各画一层底色——这样移动本身就成了信息。
- **生长**：进度环（`@property --pct` + `transition`）、色段（`scaleX`）、数字（rAF 计数）在出现时从 0 长到目标值，让"进度"这个概念有重量。数字只改文本节点，**DOM 终值永远是精确整数**。
- **三层降级**（新增动效时必须照做）：
  1. `prefersReducedMotion()`——JS 侧（计数、环形、脉冲、柔光、平滑滚动）直接跳过；
  2. `@media (prefers-reduced-motion: reduce)`——把动画/过渡压到 0.001ms；
  3. 能力探测——`document.startViewTransition`、`document.body.animate`、`matchMedia`、`getBoundingClientRect` 缺失时静默走同步/静态路径。
- **视图过渡**：`runViewTransition()` 只包**同步**的视图切换（`activateWorkbenchView`、`showDocumentView`）。

## 交互与快捷键

全局键盘只有一个 `window` 级处理器 `handleGlobalKey`（历史上 document 与 window 双挂载过，会重复触发；新快捷键不要再单独注册）。

| 键 | 作用 |
| --- | --- |
| `Ctrl+K` / `/` | 聚焦全局搜索 |
| `Ctrl+F` / `F3` / `Shift+F3` | 文档内查找 / 继续查找 |
| `[` / `]` | 当前文档上一节 / 下一节 |
| `Alt+←` / `Alt+→` | 上一篇 / 下一篇（按当前筛选范围） |
| `1` / `2` / `3` / `0` | 标记当前阅读小节：已掌握 / 待复习 / 薄弱 / 清除 |
| `M` | 打开当前小节的掌握度菜单 |
| `R` | 随机抽题菜单 |
| `T` | 切换明暗主题 |
| `?` | 打开 / 关闭帮助 |
| `Ctrl+E` / `Ctrl+S` / `Esc` | 编辑 / 保存 / 取消编辑 |

- 单键快捷键在输入态（input / textarea / contenteditable）一律不拦截。
- `Esc` 分层关闭顺序固定：掌握度菜单 → 更多操作 → 服务面板 → 随机菜单 → 搜索结果 → 查找栏 → 帮助。
- 菜单（掌握度 / 更多操作）支持 `↑↓`/`Home`/`End`/`Esc`，关闭后焦点归还触发元素；帮助弹层有 Tab 焦点陷阱。
- 掌握度标记方式：目录圆点左键开菜单、右键直接清除；标记后 Toast 带语气（成功/警告）反馈。

## 布局陷阱与修法（真实发生过，改样式前先看）

1. **目录深层标题被逐字换行**：窄列下按钮会缩到 40px 宽，中文按字折行。修法：`.toc-row .toc-link { white-space: nowrap; overflow: hidden; text-overflow: ellipsis }` + `title` 提示完整标题；父行的固定件（折叠箭头 28px + 跳转按钮 + 进度药丸）会吃掉标题宽度，所以「跳转」改为**绝对定位到行尾**、悬停/聚焦才出现，并在出现时淡出行尾进度药丸。
2. **文件行省略号失效、标题与副标题粘连**：`.fi-title` / `.fi-meta` 原本是 inline `span`，`text-overflow` 不生效且会挤在同一行。修法：`.file-copy` 改 flex 列，两个子元素 `display: block`。
3. **面包屑中等宽度竖向堆叠**：flex 子项被压缩到逐字换行。修法：crumb 子项 `flex: 0 0 auto` + `white-space: nowrap`，只有文件名 `flex: 0 1 auto; min-width: 0` 允许省略；并在 1180 / 860 / 520px 逐级让出进度 chip、文件计数、低频按钮。
4. **媒体查询顺序陷阱**：`@media (max-width: 700px)` 块写在样式表**前半段**，同特异性选择器（例如 `#file-progress`）会被后面的基础规则覆盖。修法：窄屏覆盖规则集中放在样式表**末尾**的「窄屏收尾覆盖」段。
5. **筛选栏换行**：`flex-wrap: nowrap` + 计数可省略（窄屏直接隐藏计数）。
6. **空清单面板虚高**：两列网格拉伸所致，`.home-grid { align-items: start }`。
7. **中等窗口侧栏挤掉正文**：侧栏默认 480px 在 1000px 窗口里只剩 450px 正文。修法：1180 / 860px 起默认降为 380 / 320px（仅在用户没自定义 `--sidebar-w` 时生效）。
8. **目录列过窄**：两列默认比例从 54% 改为 46%，并且**旧默认值 54 视为"未自定义"**（否则老用户永远拿不到新默认）。
9. **View Transitions 的回调是异步执行的**：不要用它包住"之后还要读 DOM 的异步流程"（例如 `openFile()` 的正文渲染——`jumpSearch` 会在 `openFile().then()` 里补高亮，包进去就会跑在渲染之前）。只包同步的视图切换；`runViewTransition` 同时挂 `.finished.catch()`，避免未处理 Promise。
10. **滑动指示条要挂在"不会被重建"的容器上**：`#tab-toc` 每次渲染都整体替换 innerHTML，指示条必须放在外层 `#col-toc`（`position: relative`），并按 `getBoundingClientRect` 相对定位、超出可视区就隐藏。
11. **`conic-gradient` 要能过渡，必须先把自定义属性注册成 `<number>`**（`@property --pct`）；未注册的自定义属性不可插值，环只会跳变。
12. **JS 动效必须门控能力**：测试桩没有 `matchMedia` / `IntersectionObserver` / `NodeFilter` / `document.querySelector` / Web Animations / `startViewTransition`，也没有元素的 `style` 对象。数字滚动尤其要门控（`document.body.animate`），否则测试会读到动画中间值。
13. **媒体查询的覆盖顺序**（同 4）：窄屏覆盖规则集中在样式表末尾，否则会被后面的基础规则盖掉。

## 维护约定

- **每次界面/交互改动，三处同步**：`README.md` 功能表、`md_viewer/UI设计评审与优化清单.md` 实施记录、`md_viewer/test_app.js` 断言。
- **两条测试必须都过**：`node md_viewer/test_render.js`（渲染器，纯 Node）与 `node md_viewer/test_app.js`（页面脚本 + 真实 HTTP，需服务已启动）。
- **测试契约（静态检查，改动时最容易踩）**：
  - JS 里出现的每个 `$("id")` 都必须在 HTML 中存在；
  - 侧栏收起/展开控件在 `toggle-sidebar` / `workspace-chevron` / `sidebar-reopen` 中**有且仅有** `toggle-sidebar`，且必须位于 `#workspace-rail` 内、`<div class="layout">` 之前，标记含 `rail-icon` 或 `ico-open`、不含 `ts-label` / `lbl-`；
  - `header` 的字面量 `position: fixed; inset: 0 0 auto; height: 58px;` 与 `.layout` 的 `margin-top: 58px;`；
  - 工作台三条选择器**出现顺序**：`body.workbench-view .workspace-rail` → `body.workbench-view aside` → `body.workbench-view #resizer`；
  - 热力图类名（`stats-heat-widget` / `-scroll` / `-months` / `-days` / `-tip` / `-summary` / `-legend` + `data-date`）；
  - `toast()` 必须用 `textContent` 写**纯文案**（图标走 CSS `::before`，不能混进文案）；
  - `#file-progress` 的 innerHTML 含「掌握 x/y」与「覆盖」；`#progress-stats` 含「进度」与「/」；
  - `randomPick(false)` 仍是"全部知识点"（旧布尔调用保持可用）；
  - 已删的入口/类名**不得复活**：`toc-tab-review`、`toc-review-count`、`toc-tabs`、`renderReviewTab`、`reviewTabActive`、`markBadgeHtml`、`cycleMark`、`rail-logo`、`rail-divider`、`stats-card`、`stats-head`、`stats-history-note`、`stats-status-item`、`review-item`；
  - 设计令牌、焦点环、动效降级、主题防闪烁脚本、唯一 `window` keydown 挂载都在；
  - 动效层：动效令牌（`--ease-expo` / `--ease-spring` / `--dur-*` / `--stagger` / `--glow-*`）、关键帧（`rise` / `bar-grow` / `mark-pop` / `pulse-ring` / `sheen` / `breathe` / `vt-out`）、`@property --pct`、`view-transition-name: pane` + `::view-transition-old(pane)`、三层降级开关（`prefersReducedMotion()` / `typeof document.startViewTransition !== "function"` / `typeof document.body.animate !== "function"`）、以及**没有任何外部依赖**（无 CDN / `@import`）都必须在。
- **测试桩约定**：`test_app.js` 的 DOM 桩会从 HTML 标记读取每个 id 的初始 class（如 `hidden`），因此"弹层分层关闭"这类逻辑能按真实行为断言；桩没有 `document.querySelector` / `NodeFilter` / `IntersectionObserver` / `matchMedia`，新代码必须像现有代码那样做特性探测，不要依赖这些 API。
- **视觉自查方法**：无头 Chrome + CDP 脚本（`--headless=new --remote-debugging-port`，`Emulation.setDeviceMetricsOverride` + `Emulation.setEmulatedMedia` 强制 `prefers-color-scheme` 深/浅，`Page.captureScreenshot`）。两个坑：`--force-dark-mode` **不会**改变 `prefers-color-scheme`（页面仍按浅色渲染），必须用 `setEmulatedMedia`；截图要等索引加载完（约 3 秒），否则拍到的是"服务正在启动中"覆盖层。截图与脚本放临时目录，不入库。
