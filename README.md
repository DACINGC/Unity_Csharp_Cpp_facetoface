# 面试笔记查看器

一个零依赖的本地网页工具，用于浏览 `面试知识整理/` 下的面试 md 文档（也支持 txt 纯文本笔记），
支持**快速跳跃到指定知识点、指定目录条目**。

## 快速开始

1. 双击 `start_viewer.bat`（或命令行运行 `python mdviewer.py --daemon`）。
2. 浏览器自动打开 `http://127.0.0.1:8765`。
3. 服务以**后台分离进程**运行：启动窗口可直接关闭，服务不受影响。
4. 管理服务：点击页面右上角 **⏻ 电源按钮**，可查看状态、**重启**或**关闭**服务。

> 需要本机已安装 Python 3（无需任何第三方库）。
> 旧方式 `python mdviewer.py`（前台运行、Ctrl+C 退出）依然可用。

## 功能

| 功能 | 说明 |
| --- | --- |
| 📁 目录条目 | 左侧「我的笔记」竖列列出全部 `.md` / `.txt` 文件，点击即打开；md 文件显示章节标题 |
| 🎛 文件筛选 | 文件列顶部可切换 **全部 / MD / TXT**，只显示对应类型的文件；「上一个 / 下一个」导航也按当前筛选范围进行，筛选状态会被记住 |
| 📂 目录折叠 | 「我的笔记」按目录分组，点击目录名可折叠/展开该目录（状态记忆，重启保持）；在折叠目录中打开文档（搜索/§ 跳转/未复习等）时自动展开该目录 |
| 📍 知识点 | 侧栏右侧竖列与文件列表**并排显示**当前文档的标题层级树（## 章节 / ### 小节），点击即跳转；两列各占满高度、独立滚动，显示更完整 |
| ↔ 侧栏宽度 | 拖动侧栏与内容区之间的分隔条可自由调整侧栏宽度（240~900px），宽度会被记住，重启后保持 |
| ↔ 目录/知识点比例 | 拖动「目录」与「知识点」两列之间的分隔条可调整两列宽度比例（28%~72%），比例会被记住，重启后保持 |
| 🏠 面包屑首页 | 点击面包屑「面试」回到知识索引（`00_知识索引.md`） |
| 🔍 文档内查找 | 面包屑「查找」或 `Ctrl+F` 在当前文档查找并高亮，`Enter`/`Shift+Enter` 上下跳转，`F3` 继续查找，`Esc` 关闭 |
| 📍 滚动跟随 | 阅读时左侧目录自动高亮当前小节，正文顶部显示阅读进度条 |
| ⏪ 前进/后退历史 | 浏览器前进/后退在打开过的文档与小节间导航，地址栏同步当前文档与锚点 |
| 🔗 分享带锚点 | 「分享」复制的链接含当前小节（`?path=…&anchor=…`），打开直达对应知识点 |
| ⌨ 快捷键帮助 | 左侧最窄栏的「?」按钮打开快捷键说明（`Ctrl+K` 全局搜索、`Ctrl+F` 文档内查找、`↑↓` 选择、`Enter` 打开、`Esc` 关闭、点击 `§编号` 跨文件跳转、`◐` 切换明暗） |
| 🔍 全局搜索 | 顶部搜索框跨全部文件匹配「章节编号 + 标题 + 文件名 + **正文全文**（含 txt）」，编号（`1.1.1`）、中文（`装箱`）、英文（`DrawCall`）均可；正文命中显示片段并**高亮定位**，txt 精确到行；`Ctrl+K` 聚焦，↑↓ 选择，回车跳转 |
| § 跨文件跳转 | 文档中所有 `§1.1.1` 形式的编号引用都可点击，自动打开对应文件并滚动到该小节（知识索引 `00_知识索引.md` 中的全部引用可用） |
| 渲染 | 标题 / 表格 / 代码块 / 加粗 / 斜体 / 删除线 / 行内代码 / 列表 / 引用块 / 分隔线，含 `List<T>` 等尖括号内容的正确转义 |
| 🔗 链接语法 | `[文本](https://…)` 外部链接新标签打开；`[文本](#1.1.1)` 同文件跳转；`[文本](01_CSharp.md#1.1.1)` 跨文件跳转 |
| ☑ 任务列表 / 折叠块 | `- [x] 已完成` 渲染为复选框；`<details><summary>题目</summary>答案</details>` 渲染为可折叠问答块 |
| ⧉ 代码块复制 | 代码块悬停显示语言标签与「复制」按钮，一键复制到剪贴板 |
| 🎯 掌握度标记 | 目录中每个知识点可点标题行尾圆点循环标记：✓已掌握 / ◔待复习 / ✕薄弱；「待复习」标签页跨文件聚合待复习与薄弱项，点击直达 |
| 📍 阅读位置记忆 | 每个文件记住上次阅读的滚动位置，重开自动恢复；分享链接 `?path=` 可直接打开指定文档 |
| 🎲 随机抽题 | 左侧工具轨「🎲」从全部知识点或「待复习/薄弱」中随机抽一个跳转，模拟面试提问自测 |
| 🖨 打印 / 导出 PDF | 工具轨「🖨」调用浏览器打印（Ctrl+P 另存为 PDF），自动隐藏侧栏顶栏、正文全宽 |
| 📊 进度统计 | 侧栏顶部实时显示全部知识点的：已标记占比、✓已掌握 / ◔待复习 / ✕薄弱 数量 |
| 📊 当前文档进度 | 面包屑栏实时显示当前文档的知识点掌握进度（进度条 + ✓/◔/✕ 计数 + 百分比），点击行尾圆点标记后即时更新 |
| ▸ 未复习定位 | 面包屑「未复习」按标题顺序（文档从上到下）定位当前文档第一个未标记的**小标题（知识点）**（跳过仅用于折叠分组的大标题），全部标完时提示；配合行尾圆点标记形成连续复习流 |
| ✎ 内置编辑 | 顶栏「✎」（或 `Ctrl+E`）进入编辑态，`Ctrl+S` 保存、`Esc` 取消；服务端按原编码（UTF-8/GBK）回写、保留行尾，写前自动备份 `.bak` |
| ⏻ 服务控制 | 顶栏电源按钮打开服务面板：实时状态（地址/端口/PID/运行时长/文档目录）、**重启服务**（新进程接管后页面自动恢复）、**关闭服务**（二次确认，防误触） |
| ⏳ 启动加载动画 | 页面打开、服务重启期间显示全屏「服务正在启动中 / 重启中」动画；连接失败自动探活重连，服务恢复后页面自动刷新 |
| 📁 文件管理器定位 | 顶栏「📁」在系统文件管理器中打开当前文件所在文件夹（仅本机） |
| 🌙 主题跟随系统 | 未手动切换过主题时，自动跟随系统明暗偏好；`/` 快捷键聚焦搜索框 |
| txt 笔记 | 纯文本等宽展示 + 行号，双击快速定位 |
| 状态记忆 | 重启后自动恢复上次打开的文档 |

## 常用参数

```bash
python mdviewer.py                 # 默认端口 8765，默认目录为脚本所在目录（含 面试知识整理/*.md 与 note、笔记 下的 txt）
python mdviewer.py --daemon        # 后台分离进程启动（关闭控制台不影响服务，start_viewer.bat 即此方式）
python mdviewer.py --port 9000     # 换端口
python mdviewer.py --root D:/docs  # 指定其他文档根目录
python mdviewer.py --no-browser    # 不自动打开浏览器
```

后台模式下会生成两个辅助文件（可随时删除，重启服务会重建）：
- `mdviewer.pid`：当前服务进程的 PID 与端口
- `mdviewer.log`：后台服务进程的输出日志（无控制台窗口时的排错依据）

## 目录结构

```
mdviewer.py                 # 本地服务（仅 Python 标准库）
md_viewer/index.html        # 前端页面（单文件，无外部依赖）
md_viewer/renderer.js       # Markdown 渲染器（纯函数，可独立测试）
md_viewer/test_render.js    # 渲染器回归测试：node md_viewer/test_render.js
md_viewer/test_app.js       # 应用冒烟测试（需服务已启动）：node md_viewer/test_app.js
start_viewer.bat            # Windows 启动脚本
```

## 说明

- 服务只监听本机 `127.0.0.1`，不对外网开放。
- 服务接口：`GET /api/service/status`（状态/探活）、`POST /api/service/restart`（重启）、`POST /api/service/shutdown`（关闭）；重启采用「先起新进程、再退旧进程」的平滑接管，页面轮询到新进程后自动刷新。
- 双击 `start_viewer.bat` 时若服务已在运行，不会重复启动，直接打开页面。
- 文档列表与章节索引带 mtime 缓存：修改 / 新增笔记后，刷新页面即可看到（自动检测文件变更）。
- 章节编号规则：标题以数字开头的 `#` / `##` / `###` 标题（如 `### 1.1.1 值类型与引用类型`）自动登记为可跳转的知识点；`§` 引用通过编号前缀匹配，找不到时给出提示。
- 文件读取按 BOM 嗅探 → UTF-8 → GBK → latin-1 顺序自动识别，兼容 Windows 记事本保存的 ANSI txt；编辑保存时按原编码回写并保留行尾，写前生成 `.bak` 备份。
